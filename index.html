Module 4: API From the Outside In

How a client talks to a server: the request, the response, and the JSON that travels inside them.

Request and Response

Request

Sent by you, received by the server.

Response

Sent by the server, received by you.

Anatomy of a request

GET https://example.com/users/5?active=true
PartExampleMeaning
Schemahttps://N/A
MethodGETWhat do I want to do?
Hostexample.comWhich server?
Path/user/5What resource?
Query?active=trueWhich/filter which ones?

Method

Method

Specific action a client requests a server to perform on a resource.

  • The server either supports it or refuses; a refusal is a 4xx error.
  • Chosen by the caller, not the server.

Types of methods

MethodDoesBody?
GETReads dataNo body
DELETERemoves dataNo body
POSTCreates dataContains a body
PUTUpdates dataContains a body

Path

Path

Determines what kind of resource and which one.

Ask yourself: Am I asking about a different thing?

Examples of paths

PathMeans
/usersAll of the users
/user/1User whose ID is 1
/postsAll of the posts
/post/1Post whose ID is 1

Query string

Query String

Optional information in the URL. Specifies extra information, filters, or parameters.

  • ? : start of a query
  • & : add another query

Path vs Query

TypeExampleMeaning
Path/post/1Give me post #1.
Query String/posts?userId=1Give me posts where userId is 1.

Header

Header

Hidden data sent with every request and response.

  • Contains the authentication when a request needs a key.
  • Declares what kind of thing.

Header examples

Content-Type: application/json
Authorization: Bearer 3|kJ8xQ…

Status codes

Status Code

Three-digit number returned by the server.

Classes

ClassMeaningExample
1xxInformationRequest received, continue processing
2xxSuccessAction was successfully received and completed
3xxRedirectionURL changed; look somewhere else
4xxClient ErrorRequest contains bad syntax
5xxServer ErrorServer failed to fulfill

Specific status codes

CodeMeansWhat to do
200 OKWorked / Found / ChangedNothing
201 CreatedCreated new resource on the serverNothing
204 No ContentResource is deleted / No body sent backNothing
301 Moved PermanentlyResource lives at a new addressUse new method
401 UnauthorizedSent no or wrong credentialsSend a key, or fix message
403 ForbiddenCredentials were valid, but not authorizedStop. More keys will not help
404 Not FoundNo such resourceCheck your path and ID
419 Page ExpiredFailed Cross-Site Request Forgery (CSRF) token validationInclude the csrf Blade directive
422 Unprocessed ContentData inside contains validation or semantic errorsFix field

422 common causes

  • Missing required fields
  • Incorrect data type
  • Invalid formatting
  • Logical or business rule violation
  • Duplicate data
  • Missing header

JSON

JSON (JavaScript Object Notation)

Universal standard data format for modern web APIs.

Object { }

Bag of keys or values.

{ "name": "Jasmine", "age": 20 }

Array [ ]

Ordered list counted from 0.

[ "Apple", "Banana", "Orange" ]

Apple → [0]   Banana → [1]   Orange → [2]

Nesting

A value can itself be an object or an array.

{ "name": "John", "address":
  { "city": "Manila" } }

Path

A way to reach a value: address → address.city

Designed to navigate, filter, and extract specific values.
