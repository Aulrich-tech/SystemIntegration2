Module 5: Build an API

Laravel routes, controllers, validation, mass assignment, and token authentication.

Route

Route

A verb and a path combined that tells the server how to direct and handle an incoming request.

Not a file on a disk, unlike about.php.

Route example

Route::get('/students', [StudentController::class, 'index']);

Route components

ComponentMeaningIn the example
Verb / HTTP MethodAction type of the request: GET, POST, PUT, DELETEget
PathThe URL pattern being requested/students
ControllerClass that handles incoming requestsStudentController
MethodFunction inside the controller: Index, Store, Show, Update, Destroyindex
Route: connects incoming requests to code.

Five routes

VerbPathMethodPurposeCode
GET/studentsIndexRead all students200
POST/studentsStoreCreate a student201
GET/students/{student}ShowShow one student200 / 404
PUT/students/{student}UpdateUpdate a student200
DELETE/students/{student}DestroyDelete a student204

apiResource

Write all five in one line.

Route::apiResource('students', StudentController::class)

Web routes vs API routes

Web Routes

Built to deliver visual interfaces directly to human users.

  • File: routes/web.php
  • Contains a Session and CSRF Token.
  • Cannot POST from Bruno.

API Routes

Built for seamless data exchange between software and programs.

  • File: routes/api.php
  • Can POST from Bruno.

Laravel project

Laravel

Open-source PHP backend web framework.

Handles server-side logic, database interaction, authentication, and application routing.

Creating routes/api.php

A fresh Laravel project does not contain routes/api.php. To create it, use:

php artisan install:api

Everything in the file is served under /api.

/students = /api/students

Route model binding

Route Model Binding

Laravel automatically looks for a corresponding record based on the placeholder value.

Placeholder and controller parameters MUST match.

Route::get('/students/{student}', [StudentController::class, 'show']);

public function show(Student $student) {
    return $student;
}

Validation

Validation

Process of inspecting and verifying the API operates accurately and securely.

validate()

Returns either clean data or stops the request with 422 and a list of which fields failed.

Example

Student::create($data) does not run when the validation fails.

Validation example

public function store(Request $request) {
    $data = $request->validate([
        'name'    => 'required|string|max:255',
        'section' => 'required|string|max:10',
        'units'   => 'required|integer|min:0|max:30',
    ]);
    return response()->json(Student::create($data), 201);
}

Fillable and mass assignment

Fillable

Specifies which fields are allowed to be set through mass assignment.

Mass Assignment

Setting multiple model fields using an array of data.

MassAssignmentException

Error when Laravel refuses mass assignment because the fields are not permitted.

Fillable example

class Student extends Model {
    protected $fillable = ['name', 'section', 'units'];
}

Query string in Laravel

Query String

Allows a request to include optional information or filters in the URL.

Query example

public function index(Request $request) {
    $query = Student::query();
    foreach (['name', 'section', 'units'] as $field) {
        if ($request->query($field)) {
            $query->where($field, $request->query($field));
        }
    }
    return $query->get();
}

Example call: GET /api/students?section=A1

Guard and token

Guard

The authentication mechanism or rule used to determine whether a request is authenticated.

Fields listed are not allowed to be mass-assigned.

That second line sits under Guard in your notes. It describes $guarded, the opposite of $fillable, so keep the two apart.

Token

Used to prove authentication when accessing protected routes.

Deleted during logout.

Token sequence

  1. POST /api/register → 201 + a token
  2. POST /api/login → 200 + a token
  3. GET /api/students without a token → 401, no token.
  4. GET /api/students with valid token → 200
  5. POST /api/logout → 204, token destroyed.
  6. GET /api/students using the same token → 401, same token, now dead.

Errors as JSON, headers

Error as JSON

Laravel can return errors in JSON format instead of an HTML webpage.

/api/* always returns JSON.

Accept Header

Tells the server what response format the client wants.

Without it, Laravel may return an HTML error or redirect to another page.

Accept header example

Accept: application/json

Content-Type Header

Tells the server what format the request body uses.

Public vs protected routes

Registrations and Logins

Sit outside the guard; they are how a caller gets a token.

Route::post('/register', [AuthController::class, 'register']);
Route::post('/login', [AuthController::class, 'login']);

Logouts

Sit inside; you need a token to invalidate it.

Public Route

A route that can be accessed without a token.

  • Registration
  • Login

Protected Route

A route that requires authentication.

  • Logout
  • /me
  • Five Student Routes

Middleware

Middleware Line

Code that runs during request handling, often to check or process a request before it reaches the controller.

Middleware example

Route::middleware('auth:sanctum')->group(function () {
    // protected routes go here
});
Only applies to everything inside the group.
